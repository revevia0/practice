# Endloops website assignment

A responsive React and Tailwind landing page for the Endloops design and build assignment.

## Run locally

1. Run `npm install`
2. Run `npm run dev`
3. Open the local URL printed by Vite

Run `npm run build` to create the production site in `dist/`.

## What is included

- Clear distinction between end-to-end solutions and standalone tools
- Keyboard-accessible, illustrative purchase-order workflow
- Responsive navigation and layouts
- Demo request form that creates an email draft
- Reduced-motion support and visible keyboard focus

The purchase-order details are sample data, not a live product demonstration. The email request currently opens a draft to Alkazim's published general address because the brief does not provide an Endloops contact address. Replace it with Endloops' approved contact channel before using this as a public company website.

The logo was extracted from the assignment PDF and is used without alteration. This project and asset are for the assignment only.
